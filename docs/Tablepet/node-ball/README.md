# 节点球 · Codex v2 桌宠包

这是基于智能客服工作台设计规范制作的正式桌宠资源。

- `pet.json`：桌宠元数据与 `spriteVersionNumber: 2`
- `spritesheet.webp`：正式 8×11 图集，1536×2288，透明背景
- `spritesheet.png`：无损检查版
- `validation.json`：桌宠图集校验结果

视觉约束：深色工作台、蓝色执行态、绿色完成态、红色异常态；角色使用圆润节点体、核心环和眼睛方向表达，不使用外部阴影、光晕或文字。

QA 预览位于 `../runs/node-ball/qa/`，包括完整 contact sheet、16 方向检查图和各状态 GIF。
