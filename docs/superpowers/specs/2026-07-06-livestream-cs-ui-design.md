# 直播间视觉向量化智能客服 · UI 原型设计

- **日期**：2026-07-06
- **状态**：已确认（待实现）
- **范围**：前端 UI 原型（React + Vite + Tailwind + TypeScript），不接后端
- **参考**：[HXS482/studio-builder-agent-final](https://github.com/HXS482/studio-builder-agent-final) 的多 Agent 架构理念；《2026 直播间视觉向量化用户调研表》字段

## 1. 产品定位与范围

### 1.1 目标
面向客户的 AI 对话式客服。通过自然对话采集《2026 直播间视觉向量化用户调研表》的 11 节信息（客户信息 → 行业品类 → 现状 → 场地 → 预算 → 商品品牌 → 对标 → 主播 → 设备 → 需求 → 备注），结构化输出给后端 Agent 系统。

### 1.2 本阶段交付
前端 UI 原型（React + Vite + Tailwind + TypeScript），**不接后端**。AI 对话用本地脚本模拟（预设问答流），数据存内存，目的是看到完整交互效果。后续可平滑替换为真实 OpenAI Agents SDK 后端。

### 1.3 不在范围内
- 真实 LLM 调用
- 向量分析 / 3D 效果图生成
- 用户登录 / 鉴权
- 持久化存储 / 后端 API

## 2. 整体架构

## 3. 左侧对话区设计

### 3.1 气泡内嵌卡片（4 种类型）
| 类型 | 用法 | 示例字段 |
|---|---|---|
| 选项卡（单选） | 圆角胶囊，点击变色 | 行业大类、品牌定位、预算档位 |
| 选项卡（多选） | 同上 + "已选 N 项"计数 | 主要痛点、看重效果 |
| 结构化输入 | 数字框 + 单位标注 | 宽×深×高、主播身高 |
| 图片上传 | 虚线框，点击/拖拽 | 场地照、商品照、对标截图 |

### 3.2 对话规则
- AI 一次只问 1 个问题（避免压迫感），必填项问完才进下一节
- 用户可随时打字补充 / 纠正（输入框常驻底部）
- 切节时 AI 有过渡语，如："行业信息够了，聊聊您的直播间现状吧"
- 用户回答后 AI 给极简确认（如"收到 ✓"），不做长篇复述（右侧表单已经回显）

## 4. 右侧仪表盘设计

### 4.1 卡片网格
11 张卡片，2 列网格。每张卡片包含：
- 标题（如"三、直播间现状"）
- 1 行摘要（如"已播 · 2000-1万观看"）
- **状态色条**：
  - 灰 `#475569` — 未采集
  - 蓝脉冲 `#2563eb` — 进行中（当前 AI 正在问的节）
  - 绿 `#34d399` — 完成（所有必填项已填）
- 缺失必填项数（如"缺 2 项"），全部填完后显示 ✓

### 4.2 就地展开编辑
点击任意卡片 → 该卡在原位展开为完整字段表单，其余卡片不动。展开卡片内复用对话区的同类组件（选项卡单/多选、结构化输入、图片上传），保证左右两侧编辑体验一致。改完点"完成"收起。展开时：
- 标题栏显示"● 编辑中" + "完成"按钮
- 必填项未填的字段用占位符 `▸ 待填` 提示

### 4.3 TopBar 进度
顶部显示总进度：`13/47` + 环形完成度图。

## 5. 采集流程与完成态

### 5.1 对话脚本驱动（原型阶段）
定义 `scriptedFlow`，按调研表顺序列出每节的关键问题。**11 节骨架，每节 2-4 个代表性问题**（不必逐字还原全部 47 字段，示意为主）。AI 按脚本推进，用户回答填入 state，右侧同步更新。

### 5.2 章节覆盖（代表性字段）
| 节 | 代表性问题（示意） |
|---|---|
| 一、客户信息 | 品牌名 / 电话 |
| 二、行业品类 | 行业大类（单选）/ 品牌定位（单选） |
| 三、直播间现状 | 是否已有 / 场均观看 |
| 四、场地条件 | 面积（单选）/ 宽×深×高（结构化输入） |
| 五、预算范围 | 总预算 / 设备预算 |
| 六、商品与品牌 | 主营商品 / 风格关键词 |
| 七、对标参考 | 是否有对标 / 主对标平台 |
| 八、主播信息 | 人数 / 身高（结构化输入） |
| 九、现有设备 | 是否有设备（在展开卡片内显示设备清单表格：类型/型号/数量） |
| 十、需求与目标 | 核心需求（单选）/ 期望交付时间 |
| 十一、客服备注 | 原型阶段省略，仅占位 |

### 5.3 完成态
所有必填项填完 → AI 发"信息采集完成 ✓"消息 → 右侧顶部出现**"生成方案"主按钮** → 点击进入**方案预览页**：
- 展示结构化 JSON（StudioFormState 序列化）
- 占位区域："场景设计说明 / 设备参数清单 / 多视角效果图 / 向量化评分报告"（标题 + 灰色 placeholder 框，模拟后端交付物）
- 顶部"返回修改"按钮

### 6.1 关键类型（schema.ts 雏形）
```ts
type FieldStatus = 'empty' | 'partial' | 'done';
type SectionStatus = 'pending' | 'active' | 'complete';

interface SectionState {
  id: string;              // 'customer' | 'industry' | ...
  title: string;           // '一、客户信息'
  status: SectionStatus;
  fields: Record<string, FieldValue>;
}

interface StudioFormState {
  sections: SectionState[];   // 长度 11
  currentSectionId: string;
  completed: boolean;
}
```

### 6.2 视觉规范
- 背景：`#0f172a`（主）/ `#1e293b`（卡片）
- 强调色：`#2563eb`（进行中/选中）/ `#34d399`（完成）
- 文字：`#e2e8f0`（主）/ `#94a3b8`（次）/ `#64748b`（弱）
- 圆角：卡片 8px、气泡 14px、胶囊 18px
- 字体：系统默认无衬线
