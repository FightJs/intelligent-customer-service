# 直播间智能搭建系统（Live Craft）

面向直播间搭建场景的 **AI 智能交付系统**。  
用户只要用自然语言说清需求，系统就能采集条件、分析定制，并直接产出可落地的搭建方案与多媒体预览——从「说想法」到「拿方案」一次跑通。

仓库：https://github.com/FightJs/intelligent-customer-service

---

## 它做什么

Live Craft 把直播间搭建从「反复沟通 → 人工出图 → 邮件往返」压缩成一条对话式流水线：

1. **听懂需求** — 多轮对话把品牌、垂类、场地、预算、产品、目标问清楚  
2. **定制方案** — 结合垂类知识库，生成设备清单、空间布局与预算规划  
3. **所见即所得** — 自动出三视图、环绕预览视频和设备与规划 PDF  
4. **一键交付** — 打包成完整交付包，可下载、可复盘、可迭代  

---

## 核心能力

### 一、客服 Agent · 对话采集需求

像一位懂行的直播间顾问，多轮把需求聊完整。

| 能力 | 说明 |
|------|------|
| **智能路由** | 按调研表状态机推进，识别当前该问什么、条件分支是否触发 |
| **路由纠偏** | 用户跑题（问报价、推荐、转人工）时及时拉回采集主线；跳过 / 不知道 / 是与否等表达由规则层直接落表 |
| **提前预选** | 选择题自动生成快捷选项，一点即答，减少重复打字 |
| **灵活采集** | 支持完整采集与快速采集；可跳过选填题，可上传现场图、参考图 |
| **会话续接** | 支持流式回复与跨会话恢复，中断不丢进度 |

**产出**：结构化调研表 `form_state` —— 全流程的唯一需求真相源。

---

### 二、方案 Agent · 定制分析与交付生成

拿到调研表后，结合垂类知识做定制化设计，直接给出「能看、能讲、能下单」的交付物。

| 交付物 | 说明 |
|--------|------|
| **设备与规划 PDF** | 空间布局、设备选型、预算分配、垂类建议，一版可汇报方案 |
| **三视图预览图** | 正面 0° / 左侧 120° / 背面 240°，看清灯光、动线与景深 |
| **环绕预览视频** | 基于主视觉生成短视频，快速感受成片效果 |
| **最终交付包** | 设备清单 Excel + 方案文档 + 图 + 视频，ZIP 一次拿走 |

工作方式：

```text
调研表 → 知识库检索 → 方案文档 → 三视图 → 环绕视频 → 交付包
```

- 方案以 `plan.json` 为唯一真相源，图、视频、清单都从它派生，避免各画各的  
- 支持失败重试、取消、成本汇总；打包前做交叉校验，保证材料一致  

---

### 三、后端与知识库 · 让方案「懂行」

| 能力 | 说明 |
|------|------|
| **业务管理** | 用户与权限、会话对话、订单与交付物、管线任务的完整 CRUD |
| **知识入库** | 管理端上传 PDF，或脚本批量导入；自动切块、向量化、可重试 |
| **向量检索** | 设备参数 / 搭建方案 / 垂类知识三库；语义 + 关键词混合检索再精排 |
| **知识关系（Graph）** | 按垂类、面积、预算档、设备类别组织知识关联，检索时沿业务条件精准导航 |

```text
需求条件（垂类 / 空间 / 预算…）
        │
        ▼
  知识关系网络 ──► 适配设备 · 搭建方案 · 垂类知识
        │
        ▼
  向量检索 + 精排 ──► 进入方案生成
```

## 系统一览

```text
用户对话
   │
   ▼
┌──────────────────────┐
│ 客服 Agent            │──► 需求调研表 form_state
│ 路由 · 纠偏 · 预选    │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐     ┌──────────────────────┐
│ 方案 Agent            │◄───►│ 后端 + 知识库         │
│ 方案 / 三视图 / 视频   │     │ CRUD · 向量 · Graph   │
└──────────┬───────────┘     └──────────────────────┘
           │
           ▼
  PDF · 三视图 · 环绕视频 · 设备清单 · ZIP
```

**技术栈**：React 19 · FastAPI · SQLite · Qdrant · Anthropic 兼容 LLM · DashScope / OpenRouter 媒体生成

---

## 适用场景

- 直播间**从零搭建**：说清预算与垂类，直接拿设备清单 + 空间方案  
- 直播间**改造升级**：上传现场图，给出可执行的优化与设备增补建议  
- 服务商**批量出方案**：标准化采集 + 模板化交付，缩短从线索到方案的周期
